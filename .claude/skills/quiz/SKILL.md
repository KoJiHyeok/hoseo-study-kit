# /quiz — 강의자료 → 객관식 4지선다 퀴즈

## 기본값 (학생이 따로 말하지 않으면)

| 항목 | 기본 |
|---|---|
| 형식 | 객관식 4지선다만 (①②③④) |
| 문항 수 | 30 |
| 배점 | 문항당 1점 |
| 범위 | 지정한 자료 1개 — 애매하면 `materials/` 에서 가장 가까운 것 |

## 흐름

1. `git pull --rebase`
2. 자료 찾기: `<과목폴더>/materials/`. 과목은 `config.json` 과 자료명으로 판별.
3. 읽기 — PDF 는 PyMuPDF 텍스트 전부 + **그림 위주 페이지는 PNG 로 렌더해 직접 본다**(그림 속 표·도식이 단골 출제 포인트). 렌더는 임시 폴더에.
4. 보조 소스: 같은 주차 `Record/summaries/*_<slug>_*.md` 의 `==강조==`, `<과목>/필기/NN주차.md` 의 "중요" → 비중을 높인다.
5. 출제 (아래 규칙)
6. 쓰기: `<과목폴더>/시험지/<NN>주차.md`. 이미 있으면 **뒤에 이어 붙인다** (번호는 기존 마지막 다음부터).
7. 검증: 정답 분포를 python 으로 집계 (①~④ 각각 대략 1/4).
8. 마무리: `python Record/site/build.py` → `site_url` 로 재배포 → commit + push.
9. 보고: 파일 경로 · 문항 수 · 범위 · 사이트 `시험지` 탭에서 풀면 된다는 것 · 그림을 못 본 페이지가 있으면 명시.

## 출제 규칙

- **자료에 있는 것만.** 근거 슬라이드·페이지를 `**출처**` 에 단다.
- 범위 고르게 — 목차 절마다 최소 1문항.
- 정답 위치 균형, 같은 번호 3연속 금지.
- 오답은 자료 속 **다른 개념**에서 가져와 그럴듯하게.
- 유형 섞기: 정의 고르기 · "옳지 않은 것"(**굵게**) · 순서 · 짝 맞추기 · 빈칸.
- 과목 `CLAUDE.md` 에 교수 출제 성향이 있으면 반영.
- 해설은 한두 줄.

## 형식 — `CLAUDE.md` 「시험지」 그대로

`**정답**` 다음 줄은 번호 하나만. 그래야 사이트에서 눌러 풀고 「전체 채점」이 된다.
