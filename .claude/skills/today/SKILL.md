# /today — 오늘 수업 한 번에 처리 (총괄 루틴)

정책 정본은 repo 루트 `CLAUDE.md`. 여기는 실행 순서만 고정한다. 과목·시간표는 `config.json`.

## 인자

- 없음 → 오늘 요일로 대상 과목 결정
- `/today 09-01` · `/today 어제` → 그 날짜 기준
- `/today <slug>` → 과목 지정(요일 무시)

## 0. 요일 → 대상 과목 (묻지 않는다)

`config.json` 의 `courses[].when`(예: `화 10–12`) 첫 글자 요일로 그날 과목을 고른다. 수업이 없는 날이면 밀린 자료 정리로 넘어간다.
요일 대상이라고 자료가 반드시 있는 건 아니다. 없으면 넘어간다.

## 1. 수집 — 총괄

```
git pull --rebase
python auto/fetch_materials.py <slug…>      # aside 있을 때. 세션 만료면 스스로 재로그인(최대 3회)
```
- `~/Downloads` 에 학생이 내려받은 PDF·PPTX·HWP 가 있으면 과목을 판별해 `<과목폴더>/materials/<NN>주차_<원본명>` 으로 옮긴다.
- 맥이고 새 LMS 영상이 있으면 `/lms-recap` (Windows 는 건너뜀).
- 주차 = `(날짜 - semester_start) // 7 + 1`.

## 2. 라우팅 — 총괄

과목 판별: ① 학생 발화 → ② 요일 → ③ 자료 내용 → ④ 그래도 모르면 묻는다.
그다음 **과목 전담 에이전트 `course-<agent>`** 를 호출 — 여러 과목이면 **한 메시지에서 병렬로**.
넘길 것: 날짜 · slug · 주차 · 자료 경로 · 전사 경로(있으면) · `exam_weekly` 여부.

## 3. 배합 요약 — 에이전트

에이전트가 자료 + 전사 + 필기(`<과목>/필기/<NN>주차.md`)를 하나의 요약으로 배합하고, 할일 · (exam_weekly 면) 시험지 · MOC 까지 갱신한다.
**총괄은 요약을 직접 쓰지 않는다.**

## 4. 마무리 — 모든 에이전트 종료 후 한 번에

```
python Record/site/build.py        # "OK: N개 노트" 의 N 이 늘었는지 확인
```
→ `config.json` 의 `site_url` 로 Artifact 재배포 (비어 있으면 새로 publish 하고 URL 을 config.json 에 적는다). 내용이 안 바뀌었으면 재배포하지 않는다.
→ `git add -A && git commit -m "recap(<semester>): …" && git push`

## 5. 보고 + 소화 — 항상 마지막

- 처리한 자료 → 쓴 요약 + 한 줄 요약
- 키워드 적중 ✅/➖ · 사이트 노트 수 · push 해시
- 새로 발견된 과제·마감
- ⭐ **오늘 소화용 질문 1~3개** — 요약 링크만 던지고 끝내지 않는다.

## 안 하는 것

- 녹음·전사 없다고 문제 삼기
- 자료용 별도 요약 파일
- 에이전트가 git·배포를 만지는 것 / 총괄이 요약을 직접 쓰는 것
- `transcripts/` · `materials/` 원본 수정
